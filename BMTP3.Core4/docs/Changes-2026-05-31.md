## Flow (BackupEngine commit-blok)

```
ITargetPathResolver.Resolve() → intendedPath
├── File.Exists?
│   ├── Nej → targetPath = intendedPath (Proceed)
│   └── Ja  → ICollisionResolver.ResolveAsync()
│       ├── Overwrite → Proceed(intendedPath)
│       ├── Skip → Skip
│       ├── Error → throw
│       └── Rename → IRenameCollisionResolver.ResolveAsync()
│           ├── Binary compare → IFileCompareService
│           ├── Hash compare → private (IHashService)
│           ├── Increment → $"{name}_{count}{ext}"
│           ├── Timestamp → $"{name}_{timestamp}{ext}"
│           ├── Hash → $"{name}_{hashShort}{ext}"
│           └── Custom → PreparedMessageFormat({count})
├── Directory.CreateDirectory()
├── IMoveableContent.MoveTo(targetPath, overwrite)
├── ISidecarService.WriteAsync()
└── record.Status = Succeeded/Skipped
```

```

↓
ResolveDate(item.DateAuthored, item.DateCreated, metadata.AuthoredDateTime, metadata.CreatedDateTime)
→ kaster InvalidOperationException hvis alle ≤ Unix epoch

↓
TargetPathResolveRequest → TargetPathResolver.Resolve() → intendedPath
├── File.Exists?
│   ├── Nej → targetPath = intendedPath
│   └── Ja  → CollisionResolveRequest → ICollisionResolver.ResolveAsync()

│       ├── Skip → Skip(intendedPath)          ← TargetPath altid sat
│       ├── Error → throw
│       └── Rename → RenameCollisionRequest → IRenameCollisionResolver.ResolveAsync()
│           ├── Increment → $"{name}_{count}{ext}"
│           ├── Timestamp → $"{name}_{timestamp}{count}{ext}"
│           ├── Hash → $"{name}_{hashShort}{count}{ext}"
│           └── Custom → FileFormatValuesRequest → PreparedMessageFormat({count})
├── Directory.CreateDirectory()
├── IMoveableContent.MoveTo(targetPath, overwrite)
├── ISidecarService.WriteAsync()
└── record.Status = Succeeded/Skipped
```
